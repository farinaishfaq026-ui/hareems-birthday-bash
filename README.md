An engaging single-page web application designed to deliver an interactive birthday experience with custom animations, modern styling, and simple web interactions.

## 🚀 Technologies Used
* **HTML5** – Semantic page structure and content layout
* **CSS3** – Custom layout design, responsive styling, and animations
* **JavaScript (ES6)** – Dynamic user interactions, event handling, and interactive elements

## ✨ Key Features
* **Responsive Design:** Optimized to fit cleanly on laptop and desktop screens
* **Interactive Elements:** Engaging click events and dynamic features built with JavaScript
* **Custom Styling:** Clean UI with personalized visual themes and smooth CSS transitions
* **Fast & Lightweight:** Built using core web technologies without heavy frameworks
